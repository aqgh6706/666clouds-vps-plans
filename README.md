## 性价比怎么判断，先看清四件事

线路比配置值钱。同样标着 1 核 1G，香港 CMI 的 50 元/月和一台普通国际线路的机器完全不是一回事。666clouds 各机房标的线路要分开看：香港是 CMI，日本走 SoftBank，韩国有 CN2/LG 和双 ISP 两种，英国做三网回程优化（移动去程 CMIN2、联通去程 AS9929），德国给的是 1Gbps 大带宽原生 IP，美国按 NTT、GTT、Cogent、AS9929、AS4837 分了好几档。线路决定你从国内连过去的延迟和晚高峰表现，配置只决定你能跑多少东西。

端口和月流量是两个独立限制。这家套餐几乎都是“端口 + 月流量”双限，200M 端口、1TB 月流量，意思是峰值能跑到 200M，一个月总共只能跑 1TB。建站、跑脚本、挂机器人这类用途，1TB 通常用不完；做视频中转、大量上传下载的，流量会先见底，端口开多大都没意义。挑之前先算自己一个月要跑多少 GB。

计费周期直接决定总价。同一个机房，月付和年付的单价能差一半，德国常规月付 55 元，年付特价折合 20.75 元/月。代价是钱一次性付掉，退款窗口内没发现问题，后面就只能自己扛。

退款窗口只有 48 小时。这家给的是 48 小时无条件退款，特价产品除外。48 小时够你装系统、跑个脚本、测一下晚高峰，不够验证一个月的稳定性。第一单别直接上年付。
